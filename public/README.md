# Drivers Voice image pack

1. Extract this ZIP.
2. Copy the `public` folder into your Next.js project root, merging folders.
3. Open `CURSOR-IMAGE-PROMPT.md` and paste its instructions into Cursor.
4. Keep `image-map.json` available for Cursor to read.

The pack includes nine matching WebP illustrations and maps all 33 page routes in your uploaded ZIP. The original application pages have not been modified.
